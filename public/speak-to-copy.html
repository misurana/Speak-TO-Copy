Settings & diagnostics

Install as an app: in Chrome tap ⋮ → “Add to Home screen” / “Install app”. The tool itself still needs internet for speech recognition.

Works in Chrome and Edge (Windows, macOS, Android) and Safari (macOS, iOS 14.5+). Firefox has no speech recognition at all. Needs microphone permission, an internet connection, and an https address — a file opened straight from disk cannot work.
